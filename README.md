## Quickstart:

### Initial test and execution
1. Install dependencies: `npm install @cityofzion/dora-ts`
2. Build SDK: `npm run build`
3. Run tests: `npm run test`

### General Use
For workflows and SDK usage, refer to the [tests](./src/tests) directory.
